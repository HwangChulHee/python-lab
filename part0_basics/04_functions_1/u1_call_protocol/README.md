# u1. 인자는 어떻게 전달되는가 — 위치, 키워드, 그리고 * **

## 지도 확인

00장 u2에서 함수 객체가 `__defaults__`를 갖는 걸 봤고,
01장 u4에서 인자 전달이 이름 바인딩(call by sharing)임을 봤다.
이번엔 **호출부에서 매개변수로 값이 배정되는 규칙**을 정리한다.
`*args`, `**kwargs`, 키워드 전용 인자까지 — 실무에서 매일 쓰지만
규칙을 정확히 아는 사람은 드문 영역이다.

## 개념 1 — 위치 인자와 키워드 인자

```python
def f(a, b, c):
    ...

f(1, 2, 3)           # 위치 인자 — 순서로 배정
f(a=1, b=2, c=3)     # 키워드 인자 — 이름으로 배정
f(1, c=3, b=2)       # 섞기 가능
f(a=1, 2)            # SyntaxError! 키워드 뒤에 위치 인자 못 옴
```

**규칙**: 위치 인자가 먼저, 키워드 인자가 나중. 섞으면 위치가 앞이어야 한다.

키워드 인자의 이점은 **호출부에서 의미가 드러난다**는 것이다.

```python
create_user("kim", True, False)              # True/False가 뭔지 모름
create_user("kim", is_admin=True, active=False)   # 명확
```

EP Item 34가 이 이야기다: 불린 플래그는 키워드로 넘겨라.

## 개념 2 — 기본값의 평가 시점 (00장 회수)

```python
def f(x=계산()):   # 계산()은 def가 실행될 때 딱 한 번
    ...
```

기본값은 **함수 정의 시점에 한 번 평가**되어 `__defaults__`에 저장된다.
호출할 때마다 다시 평가되지 않는다.

```python
import time
def log(msg, when=time.time()):     # 버그!
    print(f"{when}: {msg}")

log("a"); time.sleep(1); log("b")   # 두 when이 같다
```

`when`은 모듈이 로드된 그 순간의 시각으로 고정된다.
**동적 기본값이 필요하면 `None` 센티넬**을 쓴다 (EP Item 36).

```python
def log(msg, when=None):
    if when is None:
        when = time.time()          # 호출 시점에 평가
```

가변 객체(`[]`, `{}`)도 같은 이유로 금지다 — 01장 u4에서 본 그 함정.

## 개념 3 — *args: 위치 인자 모으기

```python
def f(*args):
    print(args)        # 튜플

f(1, 2, 3)             # (1, 2, 3)
f()                    # ()
```

**`*args`는 남은 위치 인자를 전부 튜플로 모은다.** 03장 u3의
`first, *rest`와 같은 "모으기"다. 다만 여기선 **튜플**이다(언패킹은 list).

```python
def f(a, b, *rest):
    ...
f(1, 2, 3, 4)          # a=1, b=2, rest=(3, 4)
```

**주의**: 제너레이터를 넘기면 튜플로 실체화된다.

```python
def total(*nums):
    return sum(nums)

big = (x for x in range(10_000_000))
total(*big)            # 천만 개가 전부 메모리에 튜플로! (EP Item 30 경고)
```

## 개념 4 — **kwargs: 키워드 인자 모으기

```python
def f(**kwargs):
    print(kwargs)      # dict

f(a=1, b=2)            # {'a': 1, 'b': 2}
```

**남은 키워드 인자를 dict로 모은다.** 순서는 3.7+에서 호출 순서가 보존된다.

전체 조합:

```python
def f(a, b=2, *args, **kwargs):
    ...
f(1, 3, 4, 5, x=9)
# a=1, b=3, args=(4, 5), kwargs={'x': 9}
```

순서 규칙: `일반 → 기본값 → *args → **kwargs`. 이 순서를 어기면 SyntaxError.

## 개념 5 — 키워드 전용 / 위치 전용 인자

**키워드 전용** (`*` 뒤에 오는 것들, 3.0+)

```python
def f(a, *, verbose=False):     # verbose는 반드시 키워드로
    ...
f(1, True)                       # TypeError!
f(1, verbose=True)               # OK
```

`*` 하나만 쓰면 "여기부터는 키워드로만"이라는 뜻이다.
불린 플래그나 옵션에 쓰면 호출부 실수를 원천 차단한다 (EP Item 35).

**위치 전용** (`/` 앞에 오는 것들, 3.8+)

```python
def f(a, b, /, c):              # a, b는 반드시 위치로
    ...
f(1, 2, 3)                       # OK
f(a=1, b=2, c=3)                 # TypeError!
```

매개변수 이름을 나중에 바꿔도 호출부가 안 깨지게 하려는 용도다.
표준 라이브러리 C 함수들이 이 형태다 (`len(obj)`에서 `obj=`로 못 부름).

전체 문법:

```python
def f(위치전용, /, 일반, *, 키워드전용):
```

## 개념 6 — 호출 시의 * **: 펼치기

정의부의 `*`는 모으기, **호출부의 `*`는 펼치기**다 (03장 u3에서 맛봄).

```python
def f(a, b, c): ...

args = [1, 2, 3]
f(*args)                # f(1, 2, 3)

kwargs = {"a": 1, "b": 2, "c": 3}
f(**kwargs)             # f(a=1, b=2, c=3)

f(*[1, 2], **{"c": 3})  # 섞어도 됨
```

같은 기호가 **위치에 따라 반대 방향**으로 동작한다.
정의부 = 모으기(여러 개 → 하나), 호출부 = 펼치기(하나 → 여러 개).

## 개념 7 — 바이트코드로 보면

일반 호출과 언패킹 호출이 **다른 명령**을 쓴다.

```python
f(1, 2)        # CALL 2
f(*args)       # CALL_FUNCTION_EX  ← 인자 개수를 컴파일 시점에 모르니까
f(a=1)         # KW_NAMES + CALL
```

00장 u4에서 본 CALL 규약(인자 개수를 명령에 박아넣음)이 여기서 한계를
만난다. `*args`는 런타임까지 개수를 모르므로 별도 명령이 필요하다.
(pvmlab에 `CALL_FUNCTION_EX`가 미구현인 이유이기도 하다)

## 자바와 비교

| | 자바 | 파이썬 |
|---|---|---|
| 가변 인자 | `void f(int... args)` (배열) | `*args` (튜플) |
| 키워드 인자 | **없음** | `f(a=1)` |
| 기본값 | **없음** (오버로딩으로 흉내) | `def f(a=1)` |
| 오버로딩 | 있음 (시그니처별 별도 메서드) | **없음** (이름 하나 = 함수 하나) |

**결정적 차이는 오버로딩의 부재다.** 00장 u2에서 봤듯 `def`는 이름에
대입하는 실행문이라, 같은 이름으로 두 번 정의하면 덮어써진다.
그래서 자바가 오버로딩으로 푸는 문제를 파이썬은 **기본값과 키워드 인자**로 푼다.

```java
void log(String msg) { log(msg, Level.INFO); }
void log(String msg, Level level) { ... }
```
```python
def log(msg, level=Level.INFO): ...      # 하나로 끝
```

이게 파이썬 함수 시그니처가 자바보다 유연한 이유다.

## 백엔드 관점

- FastAPI의 엔드포인트 함수가 키워드 인자로 의존성을 받는 구조가 이 규칙 위에 있다.
- 데코레이터의 `wrapper(*args, **kwargs)`는 "무엇이 오든 그대로 전달"의 관용구다
  (12장). 이걸 이해하려면 모으기/펼치기가 손에 붙어야 한다.
- 설정 dict를 `**config`로 펼쳐 넘기는 패턴은 편하지만, 오타가 런타임 에러가 된다.
  키워드 전용 인자로 명시적 시그니처를 쓰는 게 안전하다.

## 실무 규칙 (EP 연결)

- **동적 기본값은 `None` 센티넬** (Item 36). 가변 객체 기본값 금지.
- **불린/옵션은 키워드 전용으로** (`*` 사용, Item 35). 호출부 가독성과 안전성.
- `*args`에 제너레이터를 넘길 땐 메모리 실체화를 의식한다 (Item 30).
- 매개변수가 5개를 넘어가면 dataclass나 설정 객체를 고려한다.
