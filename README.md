# python-lab

파이썬 동작 원리 딥다이브. 백엔드 개발자 관점에서 "쓰고 있지만 설명 못 하는 것"을 없애는 저장소.

- 챕터는 유닛 단위로 진행: 유닛 = 개념(README) + 예제 + 유제, 실측 필요 시 measure.py
- 흐름: 개념 → 예제 실행 → 유제 → 리뷰 → 3문장 요약 직접 작성
- 새 개념마다 자바와 비교 ("같다" vs "비슷해 보이지만 다르다")
- 부가 끝나면 통합 유제 세션
- 블로그(티스토리) 초고는 유닛 README 기반
